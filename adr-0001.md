# ADR 0001 — API REST e PostgreSQL

**Status:** Proposto

## Contexto

O sistema precisa conciliar competencias dos estudantes com requisitos das vagas e gerenciar contratos de estagio.

## Decisao

Propomos uma arquitetura com API REST, Node.js e PostgreSQL. O algoritmo de Match sera organizado em um servico interno. A assinatura sera integrada por HTTPS/REST com notificacoes via webhook.

## Consequencias

### Vantagens
- Separacao de responsabilidades.
- Integridade dos dados.
- Facilidade de integracao.
- Manutencao organizada.
- Possibilidade de evolucao dos servicos.

### Riscos
- Dependencia do servico de assinatura.
- Necessidade de proteger as APIs.
- Falhas de comunicacao.
- Necessidade de tratar webhooks duplicados.
- Necessidade de avaliar continuamente o algoritmo de Match.
